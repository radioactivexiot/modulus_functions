# modulus_functions
Various functions relating to the modulus, such as RSA encryption and decryption.
Function 1: Encrypt - encrypts a number according to the RSA algorithm
Function 2: Decrypt - decrypts a number according to the RSA algorithm
Function 3: Exit - exits the script
Function 4: Inverse - Calculates the modular inverse of an input calculation (such as 2 mod 7) Checks against GCD requirement of 1
Function 5: Calculate - Calculates modular division of an input calculation (such as (2 / 7) mod 5) Checks against GCD requirement of 1
